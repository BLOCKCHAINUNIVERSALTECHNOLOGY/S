# Contributing to S

Thanks for helping.

## Setup
```bash
python3 s doctor
python3 s test
```

## Rules
1. Keep tests green (`python3 s test`).
2. Prefer small, focused changes.
3. Match existing style in `src/`.
4. Document user-facing changes in `CHANGELOG.md`.

## Pull requests
- Describe *what* and *why*.
- Link related issues.
- Do not commit secrets, keys, or large binaries.

## Reporting bugs
Use the Bug report issue template. Include:
- S version (`s version`)
- OS + Python version
- Minimal `.s` file that reproduces
