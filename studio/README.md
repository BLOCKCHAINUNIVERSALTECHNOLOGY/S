# S Studio — Editor Support (V1.1)

## What's included

- `s.language-configuration.json` — brackets, comments, auto-close
- `s.tmLanguage.json` — TextMate grammar for syntax highlighting

## VS Code / Cursor setup (manual)

1. Create extension folder or add to user languages
2. Associate `.s` files with this grammar
3. Use `python3 s` as the run task
